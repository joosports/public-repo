# JOOSPORTS Public Documents

Public-facing JOOSPORTS profiles and supporting assets.

## Published profile

- [Tse Long Tin — Player Profile](tse-long-tin-player-profile.html)

The profile provides:

- Automatic English/Japanese selection from the browser locale, with a manual language selector.
- Responsive desktop and mobile layouts.
- An accessible photo lightbox with keyboard, button, and touch navigation.
- Four-page US Letter printing with fixed JOOSPORTS headers and footers.

The site is deployed through GitHub Actions to GitHub Pages:

`https://joosports.github.io/public-repo/`
